# LIFE — Telegram Mini App v0.5

LIFE — персональный трекер жизни с локальным хранением данных. Внешний AI не подключён; статистика строится непосредственно в приложении из собственных записей.

## Что нового в v0.5

- **Исправлено управление временем.** Все поля времени используют ручной формат `чч:мм`, а также кнопки −15 / +15 минут. Можно ввести время с клавиатуры, не полагаясь на системный `input type=time` в Telegram WebView.
- Быстрые варианты времени сна и подъёма, автоматический расчёт длительности сна через полночь и оценка качества сна.
- **Редактирование** уже добавленных активностей, планов, привычек и целей. Можно изменить время, приоритет, количество, целевое значение, срок и единицу измерения.
- Задачи можно отмечать выполненными, удалять, назначать им категорию и один из трёх приоритетов. План и активность сортируются по времени.
- Привычки двух типов: обычная отметка и количественная привычка с целью за день, единицей измерения и недельной частотой.
- Цели с категорией, прогрессом, единицей измерения и сроком.
- **Свободные единицы измерения.** Например: м, км, минуты, часы, шаги, кг, мл, л, ккал, %, пульс, повторения, страницы, деньги или собственная единица.
- **Пользовательские метрики за каждый день:** добавляй показатели вроде пульса в покое, процента жира, расходов, пройденной дистанции или любой другой величины.
- **Аналитика недели:** средний сон, энергия и настроение, выполнение задач, графики шагов и продолжительности сна, прогресс и серии привычек.
- История позволяет переключать месяцы и выбирать любой день с его данными.
- Резервная копия JSON включает цели, привычки, планы, активности, метрики и историю. Формат остаётся совместим с предыдущей версией LIFE.
- Версия кеша Service Worker обновлена, чтобы у клиента была возможность загрузить новую оболочку после деплоя.

## Как обновить существующее приложение через GitHub и Vercel

1. Скачай архив и распакуй его.
2. Открой **существующий** репозиторий GitHub, подключённый к Vercel.
3. Перед заменой файлов открой LIFE → профиль и сохрани резервную копию JSON.
4. Загрузи содержимое папки проекта в корень репозитория (не сам ZIP и не вложенную папку проекта). Замени одноимённые файлы и добавь новые, если они есть.
5. Нажми **Commit changes**. Vercel должен автоматически запустить новый deployment.
6. Дождись статуса **Ready**. Открой настройки Telegram Mini App и убедись, что URL не менялся.
7. Закрой мини-приложение и открой заново. Если оно показывает старую оболочку, закрой Telegram полностью и открой снова; Service Worker с новой версией кэша должен заменить старую.

## Как проверить исправление времени

- На главной странице нажми поле **«Лёг спать»** и введи, например, `23:30`.
- В поле **«Проснулся»** введи `07:10`.
- Продолжительность должна обновиться примерно до 7 ч 40 мин.
- Попробуй изменить время кнопками `−` и `+` по 15 минут.
- Добавь активность или план и аналогично проверь время в его форме. После сохранения время отображается в записи; кнопка карандаша позволяет исправить его позже.

## Команды разработки

- `npm install`
- `npm run build`
- `npm run dev` (только для локальной разработки; для обновления опубликованного приложения localhost не требуется)

Рекомендуемые настройки Vercel: Framework `Vite`, Build Command `npm run build`, Output Directory `dist`.

## Хранение и ограничения

Данные остаются на устройстве в локальном хранилище Telegram WebView. Между устройствами они не синхронизируются. Делай резервные копии после больших обновлений. Для безопасной облачной синхронизации потребуется серверная база и проверка подлинности Telegram `initData` на сервере; нельзя помещать секретные API-ключи в фронтенд.

## Идеи из аналогов

Подход к функциям ориентирован на практичные особенности трекеров и планировщиков: быстрый ввод и приоритеты задач (TickTick/Todoist), измеримые привычки и недельная регулярность (Loop/Daylio), отчёты и сравнение здоровья во времени (Bearable). LIFE не копирует их интерфейсы и пока не содержит push-напоминаний, синхронизации с календарями, облака или настоящего AI-консультанта.
